# Changelog

## [0.4.4] — 2026-10-20

Configured development network origins for phone testing, POST-only unhydrated auth-form fallback, legacy sign-in query cleanup and theme-toggle compatibility. No schema or dependency changes. See [release notes](docs/releases/v0.4.4.md).

## [0.4.3] — 2026-10-20

Focused account-setting sections, return to the originating workspace page, a single scroll owner per screen, and replayable cedar motion with a small direct-click pull on reduced-motion devices. No schema or dependency changes. See [release notes](docs/releases/v0.4.3.md).

## [0.4.2] — 2026-10-20

Lamp-like cedar pull/swing, desktop window-height workspace layout with compact Overview and bounded long content, phone scrolling preserved, and a researched account-recovery proposal. No authentication, dependency or schema changes. See [release notes](docs/releases/v0.4.2.md).

## [0.4.1] — 2026-10-19

One account entry opens a right-hand drawer with Settings and Logout. Account settings use flat filled sections without container outlines. Each authentication route has its own illustration and purpose-specific copy, including on phones. The hanging cedar reverses its colors with the theme and pulls/flips directly on click. No schema or dependency changes. See [release notes](docs/releases/v0.4.1.md).

## [0.4.0] — 2026-10-20

Actual website company icon, direct cedar-only Light/Dark switch, illustrated auth pages, Profile with name/email/password updates and explicit Logout, shared sticky navigation, request-local session deduplication and section loading skeletons. Email changes require confirmation. No dependency or schema changes. See [release notes](docs/releases/v0.4.0.md).

## [0.3.1] — 2026-10-20

Light/Dark/System themes with a saved device preference and animated cedar pull control, grey light canvas, richer semantic colors, self-hosted Inter/Cairo typography, corrected transparent-corner app/browser/Apple icons and an explicit daily-work panel. Existing data and permissions are unchanged. No new dependencies or migration. See [release notes](docs/releases/v0.3.1.md).

## [0.3.0] — 2026-10-19

Coherent light theme and blue actions, circular logo presentation, neutral fictional examples, email password recovery, owner-only workspace renaming, direct single-workspace entry and inline project/task status updates. Adds Nodemailer; no database migration. See [release notes](docs/releases/v0.3.0.md).

## [0.2.0] — 2026-10-20

Guided client → project → task navigation, first-use setup, focused forms with optional details, built-in Help, company-only credits, original ArzCore branding and adaptive cards for compact screens. Context links are validated against the authorized workspace. Docker runtime now includes public assets. No dependency or schema changes. See [release notes](docs/releases/v0.2.0.md).

## [0.1.2] — 2026-10-20

Use ArzCore Technologies as the developer credit in the interface, README and package metadata; remove personal developer names and contact links. No schema or dependency changes.

## [0.1.1] — 2026-10-19

Clearer navigation and forms, blue action buttons, readable edit/delete controls, colored statuses, quick task progress updates, centered dialogs and success feedback. Developer credits were added; current releases use company branding. See [release notes](docs/releases/v0.1.1.md).

## [0.1.0] — 2026-10-19

Initial working foundation: authentication, organization membership, private invitations, tenant-scoped client/project/task CRUD, real dashboard counts, RBAC tests, migrations, local Docker setup and CI. See [release notes](docs/releases/v0.1.0.md).
