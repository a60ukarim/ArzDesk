# ما هو ArzDesk؟

ArzDesk برنامج ويب لتنظيم شغل فريق صغير أو مستقل: العملاء، المشاريع، والمهام. ليس صفحة بروفايل عامة. النسخة الحالية تعمل عندك محلياً إلى أن تختار استضافتها.

## مثال بسيط

| القسم    | معناه                          | مثال               |
| -------- | ------------------------------ | ------------------ |
| Clients  | الشخص أو المؤسسة التي تعمل لها | محل تجاري          |
| Projects | الشغل الذي ستسلّمه لهذا العميل | متجر إلكتروني      |
| Tasks    | خطوات صغيرة لإنجاز المشروع     | إضافة صور المنتجات |

ابدأ بإضافة العميل، ثم مشروعه، ثم المهام. بعد ذلك غيّر حالة المهمة بين To do، In progress وDone. Overview يعرض ملخص الشغل والأعداد الفعلية. البرنامج ينظّم الشغل الذي تنفّذه؛ إضافة مشروع لا تنشئ متجراً إلكترونياً تلقائياً. غيّر حالة المشروع إلى Active أثناء العمل ثم Completed عند تسليمه.

لتغيير اسم مساحة العمل: افتح Settings، عدّل Workspace name واضغط Save workspace name. هذا الخيار لصاحب المساحة Owner. لاسترجاع الحساب اضغط Forgot password في صفحة الدخول؛ إرسال البريد يحتاج إعداد SMTP، وفي التطوير المحلي يظهر الرابط في Terminal.

Team للأشخاص الذين يدخلون البرنامج للعمل معك؛ العميل المسجّل ضمن Clients لا يحصل تلقائياً على حساب. Owner يدير مساحة العمل، Admin يدير الشغل والأعضاء ضمن صلاحياته، Member يعمل على البيانات، وViewer يشاهد فقط. الدعوة رابط تنسخه وتشاركه يدوياً.

اسم المستخدم أسفل القائمة هو صاحب الجلسة الحالية. أعضاء مساحة العمل يستطيعون رؤية بيانات الأعضاء المتاحة في Team؛ الحساب ليس بروفايل إنترنت عاماً. عبارة Developed by ArzCore Technologies تعرّف بالجهة المطوّرة فقط.

## القائمة السوداء وشعار N

هذه أدوات Next.js أثناء تشغيل `npm run dev`، وليست من وظائف ArzDesk للمستخدم النهائي.

- Dynamic: الصفحة تجلب بيانات الحساب ومساحة العمل وقت الطلب. هذا متوقع لأن البيانات شخصية.
- Turbopack: الأداة التي تبني ملفات التطبيق أثناء التطوير.
- Route Info: يوضح أي ملفات كود تبني الصفحة: layout.tsx للشكل المشترك وpage.tsx لمحتوى الصفحة. orgId هو معرّف مساحة العمل وsection هو القسم المفتوح.
- Preferences: إعدادات أدوات التطوير. إخفاء المؤشر لا يحذف حساباً أو بيانات.

إذا أخفيت المؤشر مؤقتاً من قائمته، أوقف سيرفر التطوير بـCtrl+C وشغّل `npm run dev` من جديد ثم حدّث المتصفح لاسترجاعه. إذا عطّلته في الكود عبر `devIndicators: false`، أزل هذا الإعداد وأعد التشغيل. أدوات التطوير لا تظهر عند تشغيل نسخة الإنتاج.

زر Help داخل البرنامج يشرح مسار الاستخدام في أي وقت.

## المظهر

اكبس على الأرزة المعلّقة نفسها في الأعلى لتبديل Light وDark فقط. الاختيار ينحفظ بهالمتصفح ويطبّق على كل مساحات العمل.

## الحساب

اضغط اسمك أسفل القائمة أو أيقونة Profile في الأعلى. يمكنك تعديل اسمك، طلب تغيير الإيميل مع تأكيد العنوان، وتغيير كلمة المرور باستخدام الحالية. Logout داخل Profile يخرج من هذا المتصفح. تغيير كلمة المرور يخرج الجلسات الأخرى.

Progress يُحسب من مهام المشروع المنجزة: إذا خلّصت مهمة من أربع وصارت Done، النسبة 25%. In progress لا تُحسب منجزة.
