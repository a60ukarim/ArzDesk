# الحساب الأونلاين داخل تطبيق سطح المكتب

الإصدار التجريبي `0.7.0-beta.4` يفتح رابط **Open online account** في نافذة ArzDesk مستقلة عن المتصفح، بدلاً من فتح Chrome أو Edge.

- سجّل الدخول بنفس حساب الموقع. جلسة البرنامج منفصلة عن جلسة المتصفح وتُحفظ داخل البرنامج، لذلك يلزم تسجيل الدخول أول مرة.
- الأونلاين يحتاج إنترنت. لإعادة فتح الشغل المحلي، أغلق نافذة الحساب أو اختر **ArzDesk → Back to device workspaces**. تظل نافذة الجهاز الأصلية وبياناتها في مكانها.
- لا توجد مزامنة تلقائية بين Workspaces المحلية والأونلاين. لم يتغير مخطط البيانات أو قاعدة الجهاز أو أصلها `arzdesk://local` أو هوية التطبيق أو سياسة الاحتفاظ بالبيانات عند الإزالة.
- الحساب يستخدم جلسة مستقلة ودائمة `persist:arzdesk-online`، مع HTTPS لنطاق الموقع الرسمي فقط، وبدون Node أو preload أو صلاحيات جهاز داخل صفحة الحساب. الروابط الخارجية تبقى خارج نافذة الحساب.

## الفحوص

فحوص التنقل تغطي صفحات الدخول والتسجيل والملف الشخصي والدعوات والروابط المزيفة والبروتوكولات غير المسموحة.

فحص `ARZDESK_SMOKE_PHASE=online` يعمل فقط بملف QA معزول، ويستبدل استجابات HTTPS بصفحات وهمية داخل جلسة الاختبار. يفحص الضغط على الرابط المحلي، نافذة الحساب، استمرار الكوكيز بعد إغلاق النافذة وإعادة فتحها، تسجيل الخروج، فتح Profile داخل النافذة نفسها، والعودة للجهاز بدون تغيير لقطة بياناته. لا يُدخل بيانات اعتماد حقيقية ولا يكتب في قواعد الإنتاج. هذا فحص لسلوك Electron والجلسة، وليس إثباتاً لتسجيل دخول حساب حقيقي.

تشغّل مسارات بناء Windows وMac الفحوص `write` ثم `read` ثم `online` من التطبيق المعبّأ. يبقى فحص حساب حقيقي على الأجهزة الفعلية مطلوباً، ولا يفتح نجاح CI روابط تنزيل عامة تلقائياً.
