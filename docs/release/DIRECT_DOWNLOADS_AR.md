# تنزيل ArzDesk من الموقع الرسمي

صفحة `/download` هي وجهة المستخدم. روابط Windows وMac تمر عبر الموقع إلى ملفات R2 مباشرة، دون GitHub أو ChatGPT. الهواتف تستخدم `/install#installation-steps` لتثبيت PWA حالياً.

## الإصدار المجهز

الإصدار `1.0.0` مبني ومفحوص على Windows x64 وMac Intel وApple Silicon. يحتوي `releases/approved-installers.json` أسماء الملفات وأحجامها وبصماتها، ومعرّفات runs وjobs وتواريخ انتهاء الفحوص الفعلية. مصدر الملفات هو commit `13e72582b011badea855c35d7f387a82c2c2d817`.

الفحوص الآلية شغّلت التطبيق المعبّأ، وعمليات البيانات المحلية، والتصدير والاستيراد، وإعادة التشغيل، والعمل مع حجب الشبكة، ونافذة الحساب داخل Electron. Windows اختبر مثبت NSIS وإزالته؛ Mac اختبر تركيب DMG وتشغيل التطبيق بمعماريته.

هذه أدلة آلية وليست تجربة شخصية على أجهزة Windows 10 و11 أو تسجيل دخول حقيقي. تبقى `physicalTests: []` و`physicalDeviceApproval: false` في التقارير الأصلية. لا نضيف تجربة ترقية أو توقيع ناشر أو notarization غير منفذة. طلب المالك إتاحة النسخ المفحوصة من الصفحة الرسمية؛ الاعتماد الآلي مسجل بشكل مستقل عن اعتماد الأجهزة الشخصية.

## قبل دمج تفعيل الروابط

هذا التعديل مسودة حتى اكتمال الخطوات التالية:

1. ارفع الملفات المطابقة للبصمات إلى bucket `arzdesk-desktop-releases` بمسار `<fileName>` في جذر المساحة، كما رفعها المالك.
2. الملفات المرفوعة تستخدم `application/octet-stream` لتبدأ كتنزيل. عند وجود Content-Disposition، يجب أن يطابق اسم الملف. لا تستبدل نسخة منشورة ببصمة مختلفة.
3. فعّل الوصول إلى bucket الإصدار فقط. الأصل المسموح هو `https://pub-53bc8476c2234ed0be7e02fb5c528d42.r2.dev`. لا يلزم تغيير نطاق Workers أو DNS الشركة.
4. شغّل `node --import tsx scripts/verify-installer-downloads.ts`. ينزّل كل ملف ويفحص status والحجم والبصمة ونوع التنزيل أو اسم attachment ويرفض التحويلات.
5. بعد نجاح التحقق، ادمج التعديل وتحقق من نشر Vercel ومن أزرار `/download/windows` و`/download/mac-intel` و`/download/mac-arm64` على الموقع الرسمي.

رفع المالك الملفات الثلاثة إلى جذر R2؛ الأحجام وETag تطابق الملفات المفحوصة. تم تفعيل managed domain. يجب إتمام قراءة البايتات العامة والتحقق من SHA-256 قبل دمج تفعيل الأزرار.

## حماية البيانات

لا تغيير لقاعدة IndexedDB `arzdesk-device-v1` أو مخططها أو أصل `arzdesk://local` أو هوية التطبيق أو مسار بياناته. NSIS يحتفظ بـ `deleteAppDataOnUninstall:false`. فحوص Electron تستخدم مسار QA معزولاً فقط. لم تتغير Workspaces الحالية، ولم تُستخدم قاعدة الإنتاج للفحص.

لا تضع مفاتيح R2 في المستودع أو صفحات الموقع أو سجلات الاختبار. متغير `ARZDESK_RELEASES_BASE_URL` اختيار اختياري لأصل مسموح؛ وضع رابط وحده لا يعتمد ملفاً غير مفحوص.
