# تثبيت ArzDesk وتجهيز رابط التجربة

## ما الذي يثبّته المستخدم؟

نسخة v0.5.0 هي PWA: تطبيق ويب يُضاف إلى سطح المكتب أو شاشة الهاتف ويفتح بنافذة مستقلة. تحتاج الحسابات والبيانات إنترنت وخادماً مستضافاً. هذه النسخة ليست EXE أو APK ولا تعمل على البيانات دون اتصال.

افتح رابط التطبيق عبر HTTPS، ثم صفحة `/install`. على الحاسوب استخدم Chrome أو Edge وخيار تثبيت التطبيق. على Android استخدم قائمة Chrome ثم Install app أو Add to Home screen. على iPhone استخدم Safari ثم Share ثم Add to Home Screen. ظهور زر التثبيت المباشر يعتمد على المتصفح وحالة التثبيت؛ التعليمات تبقى متاحة.

رابط IP محلي عبر HTTP مناسب لتجربة الموقع على الهاتف، لكنه لا يكفي لتثبيت PWA هناك. localhost استثناء للتطوير على الحاسوب نفسه.

## إعداد الاستضافة

- أنشئ قاعدة PostgreSQL مستقلة للتجربة. لا تستخدم قاعدة المستخدم المحلية أو بيانات عملاء حقيقيين.
- اربط المستودع الخاص `a60ukarim/ArzDesk` بمضيف يدعم Next.js وNode.js. تأكد من سماح الخطة باستخدام المشروع وحدود تكلفتها قبل التفعيل.
- ضع DATABASE_URL وBETTER_AUTH_SECRET فريداً وBETTER_AUTH_URL بعنوان HTTPS النهائي في إعدادات البيئة لدى المضيف. لا تضع الأسرار في GitHub أو المحادثة.
- شغّل `npm run db:migrate` مرة على قاعدة التجربة المخصصة قبل فتح التطبيق. لا تشغّل اختبارات E2E أو TEST_DATABASE_URL على قاعدة فيها بيانات فعلية.
- البناء `npm run build` والتشغيل `npm start`. استخدم Node.js 24.
- اضبط حماية الوصول إلى النشر بشكل مستقل: Private في GitHub تخصّ المصدر، ولا تجعل رابط التطبيق خاصاً تلقائياً.

## كيف يصل رابط نسيان كلمة المرور؟

المستخدم يكتب بريد حسابه في Forgot password. الخادم يولّد رابطاً مؤقتاً ويرسله إلى بريده عبر SMTP. المستخدم يفتح الرسالة ويختار كلمة مرور جديدة. لا يظهر الرابط داخل صفحة الطلب. الرد موحّد سواء كان البريد مسجلاً أم لا.

اضبط MAIL_MODE=smtp وSMTP_HOST وSMTP_PORT وSMTP_SECURE وSMTP_USER وSMTP_PASSWORD وMAIL_FROM في بيئة الاستضافة حسب مزوّد البريد. يجب توثيق المرسل والنطاق حسب متطلبات المزوّد. استخدم عنوان HTTPS النهائي قبل إرسال الروابط.

من دون SMTP لا تصل رسالة فعلية: في التطوير المحلي فقط يظهر الرابط في Terminal. الإنتاج لا يطبع روابط الاسترجاع كحل بديل، ولا يتيح الاسترجاع عند غياب الخدمة. أرقام الهاتف وSMS وكود OTP ليست ميزات مفعّلة حالياً.

## قبل مشاركة الرابط

جرّب حساباً جديداً على جهازين، أنشئ workspace ومشروعاً ومهمة وتأكد من ظهورها بعد تسجيل الدخول على الجهاز الثاني. اختبر Logout وإرسال رسالة Forgot password فعلياً إلى بريد تملكه، ثم تغيير كلمة المرور. اختبر التثبيت على هاتف وحاسوب عبر HTTPS. عند انقطاع الاتصال تظهر رسالة إعادة الاتصال؛ لا تُخزّن صفحات الحساب أو ردود API في CacheStorage.
