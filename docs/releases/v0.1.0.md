# ArzDesk v0.1.0

First working open-source foundation for a small-team business workspace.

## Added

- Next.js App Router / React / TypeScript application with a responsive monochrome interface.
- Better Auth sign-up, sign-in, sessions, sign-out and database-backed auth rate counters.
- Multi-organization membership, workspace switching and four permission roles.
- Seven-day private invitation links with token hashing, email binding, reissue, revoke and single-use acceptance.
- Persisted clients, projects and tasks with create/edit/delete flows, search and status filters.
- Dashboard statistics calculated from the selected organization’s actual records.
- Drizzle PostgreSQL schema/migration with composite tenant foreign keys.
- Vitest service/auth integration suite and a Playwright main user story.
- Docker Compose, GitHub Actions, MIT license and contributor/security docs.

## Known limits

- Invitation links are copied and shared manually; there is no outgoing email provider.
- Email verification and password recovery are not implemented. Public signup should be reviewed before public hosting.
- Task ownership/assignees, comments, file uploads, billing and offline sync are not included.
- No ownership transfer, organization deletion or account recovery administration UI.
- English UI only. Small workspace data is loaded in a single snapshot; pagination is future work.
- Service isolation is tested; PostgreSQL RLS is not configured.
- Local Docker files and CI configuration are supplied. See the verification report for what actually ran in the authoring environment.

This release is an early portfolio/open-source baseline, not a declaration of production readiness.
