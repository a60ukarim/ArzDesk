# ArzDesk v0.4.2

- The cedar pulls down and settles with a short pendulum swing like a lamp cord; it no longer flips around its vertical axis. Direct click, keyboard access, Light/Dark persistence and reduced-motion support remain.
- Desktop workspaces use the window height with a fixed navigation/header and a separate content pane for longer data. Overview spacing is compact enough for common laptop windows, including 1366×640. Project/task summaries can scroll internally when needed, without discarding records or shrinking text with page zoom.
- Desktop account settings keep their header in view with long forms in a content pane. Phone/tablet pages retain normal page scrolling. Desktop authentication screens use more compact spacing on short laptop windows.
- Password recovery still uses the existing emailed reset link. No OTP/SMS service or paid subscription has been activated. See the [recovery options](../account-recovery-plan.ar.md) for costs and the proposed next step.
- No database migration or dependency change. Preserve `.env` and PostgreSQL data, overwrite source contents, clear `.next` and restart.
