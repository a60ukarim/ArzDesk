# ArzDesk v0.3.1

- Light, Dark and System appearance modes, saved on this device and applied before the main interface loads. Click the hanging cedar to animate the cord and toggle light/dark, or use its arrow menu to follow the system. Dark neutrals and the control follow the ArzCore website reference. Reduced-motion preferences disable the animation.
- A grey app canvas with softened surfaces, purple action controls and blue/purple/amber/green statistic cards. Statuses retain text labels.
- Inter Black headings and Cairo Arabic text, bundled locally with their SIL Open Font License notices.
- App logo and browser icon share a circular SVG frame around the original supplied artwork. The SVG itself clips the black exterior, so the fix works outside app CSS. New asset URLs avoid the old favicon cache. A PNG export covers browsers and Apple home-screen icons.
- An overview panel explains the daily loop: open a task, mark it In progress, do the actual work in your usual tools, then mark it Done. ArzDesk records and summarizes progress.

## Upgrade

Preserve `.env` and PostgreSQL data, overwrite source files, remove `.next` and restart. From v0.3.0, no dependency install, migration or seed is required. From earlier versions, first run `npm ci` for the v0.3.0 email dependencies. See [Windows instructions](../../UPDATE_AR.md).

No deployment or repository push is included.
