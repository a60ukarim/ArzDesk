# ArzDesk v0.5.0

- Dedicated purple/mint ArzDesk product mark with a transparent background, used in the brand, browser tab and app manifest. ArzCore attribution and the hanging cedar theme control remain.
- Public `/install` page with computer, Android and iPhone instructions and an install prompt when supported. Pending browser invitations survive client-side navigation.
- Production-only service worker and standalone web app manifest. Network-only workspace access, no private response cache and no offline edits. Connection failures show a reconnect page.
- Installation links in the authentication footer and account drawer.
- Private repository and HTTPS/PostgreSQL/SMTP setup documentation. No migration or dependency change. Preserve existing `.env` and database on update.

A GitHub source download is not a native installer. A working shared trial URL still requires hosting and a configured database; password recovery requires SMTP.

## Validation

Production build, TypeScript, ESLint and formatting passed; 30 unit/database/auth tests and eight production browser flows passed. Browser checks cover workspace CRUD/invitations/role restrictions, SMTP recovery using a local test mail server, account edits, theme behavior, authentication illustrations and responsive installation screens. Installation checks verify the manifest/icon, a simulated browser install invitation surviving navigation, real service-worker registration and offline fallback with no CacheStorage entries. A physical-device installation and a live hosted deployment have not been verified.
