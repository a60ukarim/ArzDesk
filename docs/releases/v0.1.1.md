# ArzDesk v0.1.1

Usability and developer credits update.

- Blue primary actions and selected navigation; distinct project, task and role colors.
- Plain page headings, a three-step getting-started guide and contextual next actions.
- Labeled Edit/Delete buttons, field examples, required/optional markers and form hints.
- Centered, scrollable dialogs and success notifications.
- Direct task status changes with server-side role checks and tenant scoping, without overwriting task details.
- Mobile navigation and touch target improvements.
- Developer credits added; current releases use company branding.

No database schema or dependency changes. Existing accounts, workspaces and data use the same database. Keep your local `.env` and `node_modules` when copying source files. See [Arabic update steps](../../UPDATE_AR.md).

Known v0.1.0 limitations still apply. This update does not create developer user accounts or send invitations.
