# ArzDesk v0.4.0

- Branding and favicon now use the actual PNG from the ArzCore website, without a custom crop or redraw.
- Light and Dark only. Click the hanging cedar itself to animate it and toggle appearance; no surrounding button panel, menu or System option. Keyboard access and reduced motion remain supported.
- Authentication pages replace sample records with a responsive geometric illustration.
- Profile opens from your name or account icon: name update, verified email change, current-password-protected password change and explicit Logout. Changing a password revokes other sessions.
- A verified email must approve the change at the old address, then confirm the new address. Unverified accounts confirm the new address. SMTP or the existing development-terminal fallback is required; the old address remains active until confirmation.
- Workspace navigation stays mounted between sections and visible during scrolling. Request-local session deduplication avoids repeated auth lookups within one render; small page skeletons replace the global workspace-loading message. Navigation prefetches on focus/hover, rather than fetching every section at once.
- Project copy explains that progress increases as tasks are marked Done.

## Upgrade

From v0.3.0 or v0.3.1: preserve `.env` and PostgreSQL data, overwrite source contents, clear `.next` and restart. No new dependency install, migration or seed. From earlier versions, run `npm ci` first. See [Windows instructions](../../UPDATE_AR.md).

Real email delivery requires operator SMTP configuration. Development links remain private to the server terminal. First-time development compilation and network/database latency can still cause short waits. No deployment or GitHub push was performed.
