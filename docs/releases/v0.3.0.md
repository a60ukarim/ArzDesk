# ArzDesk v0.3.0

A consistent light interface with blue actions, readable onboarding and fictional examples: A local shop → Online store → Add product photos. The original logo is displayed within its circle, removing the surrounding black corners.

- Owners can rename the workspace in Settings; other roles cannot. Existing records stay attached.
- A user with one workspace enters its overview directly after normal sign-in. Invitation redirects remain supported.
- Projects and dashboard tasks have direct status controls, with server-side role checks.
- Forgot password supports SMTP email, one-use 15-minute links and session invalidation. Development can print the link to the local server terminal. Production requires SMTP settings.

## Upgrade

Preserve `.env` and your PostgreSQL database. Install the updated dependencies with `npm ci`, clear `.next` and restart. No new database migration or seed is required. See [Windows instructions](../../UPDATE_AR.md).

Nodemailer and its TypeScript definitions are new dependencies. External SMTP credentials and sender configuration are not supplied. No hosted deployment, external email delivery or GitHub release was performed.
