# ArzDesk v0.4.3

- Account settings show one form at a time: Your name, Email address, or Password. Keyboard navigation works across the section tabs. Forms fill their available column without an unused strip inside wide cards.
- Back returns to the local application page that opened account settings, including its query and workspace. It no longer sends ordinary account-settings visits through the workspace chooser. The return destination survives reloads in the same tab; direct visits without a stored destination fall back to the normal start page.
- Desktop workspace screens explicitly assign scrolling to the content pane and keep the document from becoming a second scroll container. Account settings use the document scrollbar, with no narrow scrolling column inside the page. Mobile pages retain normal document scrolling.
- Cedar motion uses a replayable pull-and-swing interaction on each activation, including consecutive clicks. Devices requesting reduced motion get a short, small pull in response to the explicit click instead of the full swing.
- No dependency, database or authentication-backend changes.

## Upgrade

Keep `.env` and PostgreSQL data. Stop the server, overwrite source contents, clear `.next`, restart and refresh the browser. No dependency reinstall, migration or seed is needed from v0.3.0 or later.

## Validation

Production build and ESLint passed. Five production browser flows passed, including account name/email/password changes and session revocation, exact-origin Back navigation, responsive account sections, repeatable theme motion, workspace navigation/permissions and auth screens. The account and theme flows also passed against `npm run dev`; scroll checks include classic-width scrollbars and reduced-motion input feedback. Screenshot review covered phone and desktop layouts.
