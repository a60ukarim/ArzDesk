# v0.6.0 — device workspaces

ArzDesk now offers a local workspace mode at `/offline`, using the existing client/project/task interfaces without a session or network connection after initial setup. Device storage uses IndexedDB transactions; multiple workspaces and browser tabs are supported. Backups are versioned JSON and import as additional workspaces, with validated tenant/parent relationships and remapped IDs. A signed-in user can explicitly copy readable online workspaces to independent local copies. No local changes are uploaded or automatically synchronized.

The production build generates a versioned list of public shell assets. The service worker installs atomically and caches the public offline document, scripts, styles, fonts and images only. Authenticated pages and API responses remain network-only. The install start URL is `/offline`. Account pages and install instructions link to local mode.

Success notifications now fit their text, wrap safely on narrow screens and keep the dismiss control at the edge, above the device safe area.

Limitations: first preparation requires internet; storage is specific to a browser profile and device; backups are necessary; team sharing and auth need internet; EXE/APK packaging and automatic sync are not part of this release.

Validation: lint, TypeScript and a clean production build passed. All 35 unit/database/auth tests passed using disposable PGlite. Six targeted production browser flows passed, including offline CRUD and reload, backup restoration and invalid-file rejection, two-tab concurrent saves, quota-failure feedback, a complete persistent-browser restart while offline, install prompts, responsive layouts and cache boundaries. Live cloud copying with an authenticated production account and native EXE/APK installation were not exercised.
