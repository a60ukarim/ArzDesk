# ArzDesk v0.2.0

## Work flow

- Overview guides new workspaces through a client, project and task instead of showing empty dashboards.
- Client names open their projects. A client row can create a project with that client selected.
- Project names open their tasks. New tasks inherit the current project selection.
- Context remains in shareable URLs, survives reload and can be cleared. Invalid or foreign-workspace context is refused.
- A visible client → project → task trail, navigation descriptions and contextual empty states explain the next action.
- Built-in Help explains the three records and distinguishes clients from team accounts.

## Forms and layout

- Creation forms show only the essential inputs; optional details expand on demand. Edit forms expose existing details.
- Compact screens use record cards with labels, rather than horizontally panning tables.
- Top navigation on phones/tablets; sidebar on wider screens. Touch controls, scrollable dialogs and reduced-motion preferences are supported.
- Original user-supplied ArzCore logo, browser icon and company-only developer credit. Team lists show actual workspace members.
- Docker runtime copies the new public assets directory.

No dependency or database schema changes. Keep existing environment settings and data. See [Arabic update steps](../../UPDATE_AR.md), [user guide](../how-it-works.ar.md) and [verification](../verification.md).

The earlier product limitations still apply. Native PostgreSQL, Docker and physical-device browser coverage are distinct from the authoring environment checks.
