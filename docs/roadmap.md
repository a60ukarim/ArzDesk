# Roadmap

## v0.1.0 — Working foundation

- [x] Next.js / TypeScript / Tailwind, local shadcn-style Button and feature folders
- [x] Better Auth credentials and sessions
- [x] PostgreSQL / Drizzle schema and committed migrations
- [x] Organization creation, membership and switching
- [x] Owner / admin / member / viewer authorization
- [x] Private invitation creation, acceptance, revocation and reissue
- [x] Client, project and task CRUD
- [x] Real dashboard counts
- [x] Authorization and tenant-reference database tests
- [x] Playwright main workflow, CI, Docker and contributor docs

## v0.2.0 — Guided work flow and responsive usability

- [x] First-use setup and built-in quick guide
- [x] Client → project → task context links and preselected create forms
- [x] Focused forms with optional details
- [x] Original ArzCore logo and company-only developer credits
- [x] Adaptive tables/cards, touch controls and phone/tablet navigation
- [x] Browser checks at 11 viewport widths from 320 to 1920 pixels, plus landscape dialogs

## v0.3.0 — Clearer everyday use

- [x] Consistent light theme and circular logo presentation
- [x] Neutral examples and a clear explanation of the daily work flow
- [x] Owner-only workspace renaming and single-workspace direct entry
- [x] Inline project and dashboard task status updates
- [x] Password reset with optional SMTP delivery and safe development fallback

## v0.3.1 — Appearance and typography

- [x] Saved Light / Dark / System appearance (superseded by Light/Dark only in v0.4.0)
- [x] Animated cedar pull control based on the ArzCore website
- [x] Grey light canvas and warm charcoal dark surfaces with semantic colors
- [x] Inter Black headings and Cairo Arabic font, self-hosted with license notices
- [x] Circular app, browser and Apple icons with transparent corners
- [x] Clear everyday work panel

## v0.4.0 — Account controls and persistent navigation

- [x] Company website icon used directly in the app and favicon
- [x] Cedar-only Light/Dark control; System removed
- [x] Illustrated authentication pages
- [x] Profile with name, confirmed email and password changes
- [x] Explicit Logout with one navigation after server confirmation
- [x] Shared sticky workspace shell and section loading skeletons
- [x] Short-height desktop navigation and phone/tablet checks

## Candidate next release — Day-to-day collaboration

These are proposed next steps; no release date is committed.

- Server-side pagination, filtering and SQL dashboard aggregates
- Task assignees, comments, activity log and project detail pages
- Email verification and invitation delivery through an explicit provider
- Ownership transfer and organization lifecycle management
- Arabic interface and RTL support
- Organization-level anti-abuse quotas and audit events

## Later exploration

Notifications, attachments, optional offline behavior and reporting. Payments, subscriptions, AI features and mobile apps are outside v0.1.0.
